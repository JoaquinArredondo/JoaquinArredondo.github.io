- `portfolio-core.css` — global design system, technical-evidence cards, document viewers, responsive behavior, and lightbox styling.
- `portfolio.js` — lightweight reveal motion plus the accessible technical-image lightbox.
- `images/technical-evidence/` — Unity Inspector, debug, and gameplay screenshots used as technical proof.
- `documents/` — embedded portfolio documentation and research PDFs.

## Deployment
The site is plain HTML/CSS/JS. Copy the contents of this folder to the root of `JoaquinArredondo.github.io` and push to the GitHub Pages branch. Keep `index.html` at repository root.

See `IMPLEMENTATION_REPORT.md` for the latest revision notes, validation results, and remaining missing assets.
